# MediHome

Sistema de atención médica domiciliaria. Diseño de Software, Universidad Cooperativa de Colombia, sede Pasto.

## Integrantes

- Santiago Alejandro Campoverde Obando 
- Juan David Moreno Alfaro

## Contenido

- `src/`: programa Java con las clases del modelo y la clase Main
- `diagrama/MediHome.png`: imagen del diagrama de clases
- `diagrama/MediHome.vpp`: archivo fuente de Visual Paradigm

## Cómo ejecutar

Abrir el proyecto en IntelliJ IDEA y ejecutar `Main.java`. El programa imprime el reporte de la atención prestada al paciente.
